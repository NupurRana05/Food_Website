# Food_Website
Welcome to my Food Website Clone project!
This is a fully responsive food ordering website built using HTML and CSS only. It showcases a restaurant interface where users can browse different cuisines like Punjabi, Indian, Chinese, and South Indian, and also reserve their seat online.
Features:-
 Multiple cuisines: Punjabi, Indian, Chinese, South Indian

 Attractive UI with food images and hover effects

 Reserve Your Seat section for booking tables

 Easy navigation with clean layout and smooth user experience
